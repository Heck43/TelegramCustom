# Roadmap: TelegramCustom

Дорожная карта проекта основана исключительно на текущих задачах, требованиях пользователя и выявленных технических вызовах.

---

## Фаза 1: Немедленный этап (Immediate / Next Step)
> **Цель:** Восстановить зелёный билд в CI/CD и подтвердить решение проблем пользователя.

1. **Исправление синтаксиса RPL в `in_game_overlay.hpp`:**
   - Заменить `| rpl::start_with_next(...)` на валидный синтаксис подписки.
   - Запушить коммит в ветку `main`.
2. **Верификация сборки в GitHub Actions:**
   - Дождаться успешного завершения пайплайна (компиляция MSVC 2022, линковка, сборка артефакта).
3. **Пользовательское тестирование:**
   - Подтвердить загрузку полной истории в чатах («Марат» и др.) без захода в основном окне Telegram.
   - Подтвердить автоматическую смену размытых плейсхолдеров на четкие HD-миниатюры.

---

## Фаза 2: Краткосрочный этап (Short Term)
> **Цель:** Шлифовка и оптимизация оверлея.

1. **Ограничение пропорций вертикальных медиа:**
   - Настройка максимальной высоты картинок (`maxH = 200–220px`) для комфортного чтения переписки при отправке длинных скриншотов.
2. **Оптимизация повторной загрузки:**
   - Кэширование проверенных слайсов истории, чтобы при частом переключении между чатами не слать повторные запросы `MTPmessages_GetHistory` без необходимости.
3. **Синхронизация палитры оверлея с кастомной темой:**
   - Привязка фонов облачков (`#0284C7`, `#1E293B`) к переменным темы `st::msgOutBg` и `st::msgInBg` для полной гармонии с выбранной темой клиента.

---

## Фаза 3: Среднесрочный этап (Medium Term)
> **Цель:** Игровые интерактивные функции.

1. **Внутриигровые уведомления (Corner Toasts):**
   - Полупрозрачное компактное уведомление о новом личном сообщении в правом верхнем/нижнем углу игры.
   - Нажатие горячей клавиши (например, `Ctrl + Enter` или клик) открывает оверлей сразу на нужном чате.
2. **Панель голосового чата в шапке оверлея:**
   - Отображение статуса активного голосового звонка / стрима.
   - Кнопка быстрого отключения/включения микрофона (Mute) прямо из оверлея.

---

## Фаза 4: Долгосрочный этап (Future Improvements)
> **Цель:** Удобство дистрибуции и экосистема.

1. **Автономный установщик:**
   - Создание InnoSetup-скрипта в CI/CD для генерации `TelegramCustom-Setup.exe`.
2. **Встроенная проверка обновлений:**
   - Проверка новых релизов через GitHub Releases API без использования официальных серверов обновлений tdesktop.
