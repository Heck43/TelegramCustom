# Project Overview: TelegramCustom

## 1. Назначение и концепция проекта

**TelegramCustom** — это модифицированная сборка официального клиента **Telegram Desktop (tdesktop v7.0.9)** для Windows x64, созданная для максимального комфорта геймеров, продвинутых пользователей и тех, кто ценит приватность и персонализацию.

Официальный Telegram Desktop ориентирован на офисное и мобильное использование, из-за чего в нём отсутствует ряд критически важных функций для настольной рабочей среды и игр:
1. **Отсутствие игрового оверлея:** Невозможно читать и отправлять сообщения поверх запущенных игр (DirectX 11/12, Vulkan, OpenGL), не сворачивая окно игры через Alt+Tab.
2. **Перегрузка рекламой:** В каналах принудительно отображаются коммерческие спонсорские посты Telegram Ad Platform.
3. **Ограниченная панель стикеров:** Список недавних стикеров ограничен небольшим количеством элементов, что замедляет общение.
4. **Хаос в загрузках:** Все скачиваемые медиа, документы, архивы и программы сваливаются в единую папку `Downloads/Telegram Desktop`.
5. **Несоответствие теме Windows:** Стандартные темы Telegram не реагируют на смену обоев рабочего стола Windows и Wallpaper Engine.
6. **Отсутствие автоблокировки:** При блокировке экрана Windows (`Win + L`) открытый клиент Telegram остается разблокированным.

## 2. Ключевые возможности

### 🎮 Внутриигровой оверлей (In-Game Overlay)
- Вызывается в любой момент поверх запущенных игр по глобальным хоткеям: `Shift + ~` (тильда), `Shift + F11`, `Ctrl + Shift + O`, `Alt + ~`.
- Ультратёмный полупрозрачный интерфейс (окно `960x640`, 99% непрозрачности `#080B10`).
- Доступ к реальному списку диалогов, переписке и аватарам собеседников.
- Отображение реального статуса онлайна собеседника («в сети», «был(а) недавно» и т.д.).
- Поддержка многострочных сообщений без обрезания текста.
- Поддержка превью медиа (фото, GIF, видео) прямо внутри облачков сообщений.
- Поле быстрого ввода с отправкой сообщения по Enter.
- Режим «только для чтения» с баннером при открытии информационных каналов.
- Поиск по списку чатов в реальном времени.

### 🎨 Динамическая синхронизация акцентного цвета Windows / Wallpaper Engine
- Клиент отслеживает акцентный цвет Windows из реестра (`DwmGetColorizationColor`, `HKCU\Software\Microsoft\Windows\DWM\AccentColor` и `AccentPalette`).
- При смене обоев Wallpaper Engine или темы Windows акцентные элементы интерфейса Telegram (кнопки, выделения, галочки, активные диалоги) плавно меняют цвет в реальном времени.

### 📁 Умный роутер загрузок (Downloads Router)
- Автоматически классифицирует скачиваемые файлы по их расширениям и сохраняет в соответствующие подпапки:
  - `Downloads/Telegram Desktop/Изображения` (jpg, png, gif, webp, svg, heic, etc.)
  - `Downloads/Telegram Desktop/Музыка` (mp3, flac, wav, ogg, m4a, etc.)
  - `Downloads/Telegram Desktop/Видео` (mp4, mkv, avi, mov, webm, etc.)
  - `Downloads/Telegram Desktop/Документы` (pdf, docx, xlsx, txt, epub, json, etc.)
  - `Downloads/Telegram Desktop/Архивы` (zip, rar, 7z, tar, gz, etc.)
  - `Downloads/Telegram Desktop/Программы` (exe, msi, dll, bat, etc.)

### 🛡️ Приватность и безопасность
- **Блокировка рекламы:** Спонсорские сообщения Telegram Ad Platform блокируются на уровне обработчика данных.
- **Очистка ссылок:** При клике на внешние ссылки автоматически вырезаются трекинговые метки (`utm_source`, `utm_medium`, `si`, `fbclid`, `gclid`, `yclid`, `igshid` и др.).
- **Прямой переход:** Возможность отключить предупреждающее окно подтверждения перехода по внешней ссылке.
- **Автоблокировка:** При нажатии `Win + L` Telegram переходит в заблокированное состояние (если установлен локальный пароль).

### ⚡ Расширенный список стикеров
- Лимит недавних стикеров увеличен до **300 штук** (вместо стандартного ограничения).

## 3. Стек технологий

- **Язык программирования:** C++20 (MSVC 2022 / toolset 14.44).
- **GUI Framework:** Qt 5/6 Widgets (нативная часть `tdesktop`), QPainter, кастомный CSS-стилизатор.
- **Сетевой протокол:** Telegram MTProto 2.0 (нативная библиотека Telegram API).
- **Платформа:** Windows 10/11 x64 (Win32 API: `SetWindowsHookEx`, `WtsApi32`, `DWM API`, `Toolhelp32`).
- **Система сборки:** CMake, Ninja, MSBuild, Python (для генерации ресурсов).
- **CI/CD:** GitHub Actions (`windows-latest`, кэширование сторонних C++ библиотек `win64`, публикация артефактов).
