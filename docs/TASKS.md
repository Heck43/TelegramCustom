# Tasks: TelegramCustom

В этом документе ведется строгий учёт всех задач проекта с распределением по категориям готовности.

## 1. COMPLETED (Завершено и проверено)

### TASK-001: Глобальный перехватчик хоткеев для вызова оверлея
- **Описание:** Перехват `Shift + ~` и вызов окна оверлея поверх 3D-приложений.
- **Связанные файлы:** `custom_features/in_game_overlay.hpp`, `platform/win/main_window_win.cpp`.
- **Что сделано:** Зарегистрирован хук `SetWindowsHookEx(WH_KEYBOARD_LL)`, добавлен черный список окон рабочего стола.
- **Результат:** Оверлей стабильно открывается и закрывается в играх.

### TASK-002: Устранение обрезания многострочного текста в сообщениях
- **Описание:** Сообщения длиннее одной строки обрезались по вертикали.
- **Связанные файлы:** `custom_features/in_game_overlay.hpp` (`addMessageBubble`).
- **Что сделано:** Пузыри сообщений обёрнуты в контейнер `rowWidget` (`QHBoxLayout` + `addStretch`), включен `setWordWrap(true)` и `setSizePolicy(Preferred, Minimum)`.
- **Результат:** Текст любой длины переносится и полностью отображается.

### TASK-003: Нативная стилизация скроллбаров
- **Описание:** Убрать стандартный белый скроллбар Windows со стрелками.
- **Связанные файлы:** `custom_features/in_game_overlay.hpp` (`setupUI`).
- **Что сделано:** Стилизация через `setStyleSheet` назначена напрямую на объект `verticalScrollBar()`.
- **Результат:** Тонкий 6px темный полупрозрачный скроллбар.

### TASK-004: Отображение реального статуса собеседника
- **Описание:** Вместо заглушки «Личные сообщения» показывать реальный статус онлайна.
- **Связанные файлы:** `custom_features/in_game_overlay.hpp` (`FormatPeerStatusText`), `data/data_peer_values.h`.
- **Что сделано:** Интегрированы `Data::OnlineText` и `Data::OnlineTextActive`.
- **Результат:** Подсвечивается статус «в сети» (#38BDF8), время отсутствия или число участников группы.

### TASK-005: Поиск по диалогам в реальном времени
- **Описание:** Быстрая фильтрация списка диалогов в левой колонке оверлея.
- **Связанные файлы:** `custom_features/in_game_overlay.hpp` (`filterDialogs`).
- **Что сделано:** Добавлена фильтрация виджетов по свойству `property("peerName")`.
- **Результат:** Список мгновенно фильтруется по подстроке.

### TASK-006: Базовые пользовательские модификации
- **Описание:** Блокировка рекламы, 300 стикеров, роутер загрузок, очистка трекеров в ссылках, блокировка по `Win + L`, синхронизация акцентного цвета Windows.
- **Связанные файлы:** `custom_features/*`, `settings/sections/settings_custom.cpp`.
- **Результат:** Полностью работают и настраиваются через меню настроек.
