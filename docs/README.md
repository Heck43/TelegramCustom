# TelegramCustom — Documentation Hub

Добро пожаловать в систему технической документации **TelegramCustom** — специализированного форка Telegram Desktop (tdesktop) с расширенными игровыми и пользовательскими возможностями.

Этот каталог (`/docs/`) содержит полное и исчерпывающее описание архитектуры, функционала, принятых решений, текущего состояния кодовой базы и инструкций для продолжения разработки.

## START HERE (Руководство для нового ИИ / разработчика)

Если вы только что открыли проект и должны продолжить разработку:

1. **Шаг 1:** Прочитайте [**HANDOFF.md**](HANDOFF.md) — узнайте, на чем конкретно остановилась работа, какая ошибка возникла в последнем коммите и какую строку нужно исправить в первую очередь.
2. **Шаг 2:** Откройте [**CURRENT_STATE.md**](CURRENT_STATE.md) — оцените актуальный статус рабочего дерева и CI/CD билдов.
3. **Шаг 3:** При необходимости погружения в устройство подсистем изучите [**ARCHITECTURE.md**](ARCHITECTURE.md) и [**FILE_STRUCTURE.md**](FILE_STRUCTURE.md).
4. **Шаг 4:** Проверьте реестр багов в [**PROBLEMS.md**](PROBLEMS.md), чтобы не повторять уже опробованные неработающие решения.
5. **Шаг 5:** Приступайте к выполнению шагов из раздела `Next Action` файла [**HANDOFF.md**](HANDOFF.md).
