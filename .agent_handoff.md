# Technical Handoff State

## 1. Implemented Features

### 1.1 In-Game Overlay
- Global low-level hook `WH_KEYBOARD_LL` (`Shift + ~`, `Shift + F11`, `Ctrl + Shift + O`, `Alt + ~`).
- Game foreground filter: ignores `Progman`, `WorkerW`, `Shell_TrayWnd`, `explorer.exe`, `dwm.exe`. Matches allowed processes (`overlayAllowedGames`) or all games (`overlayAllGames`).
- Window size: `960x640`, background `#080B10` (99% opaque).
- Live `Main::Session` data integration:
  - Real peer avatars: `GeneratePeerAvatarPixmap` using `peer->createUserpicView()`, `peer->loadUserpic()`, `peer->paintUserpicLeft()`, `EmptyUserpic`.
  - Real dialogs list: `session->data().chatsList()->indexed()->all()`.
  - Real message history: reverse iteration over `history->blocks`, text and media preview via `item->notificationText().text`, timestamps (`HH:mm`).
  - Inline image thumbnails rendering inside overlay chat bubbles for photos, GIFs and video animations via `GenerateMediaThumbnailPixmap` (`PhotoMedia` / `DocumentMedia` / `getReplyPreview`) with rounded antialiased clipping, HiDPI scaling, and GIF badges.
  - Server-side asynchronous fetching of dialogs and message history (`session->api().requestDialogs()`, `session->api().requestHistory()`) so history & chats load without needing to open them in the main Telegram window first.
  - Real peer online status & last seen display (`FormatPeerStatusText`, `Data::OnlineText`, `Data::OnlineTextActive`) with active online indicator in chat header.
  - Auto-expanding multi-line text bubbles with `rowWidget` layout to avoid vertical text clipping on long sentences.
  - Real-time search filter in dialogs list.
  - Clean custom dark scrollbars applied directly to Qt vertical scrollbars.
  - Read-only banner for channels (`peer->isChannel() && !peer->isMegagroup()`).
  - Outgoing message sending via `session->api().sendMessage(Api::SendAction(_activeHistory), text)`.
  - Background 2.5s auto-refresh timer for live updates of online status, unread badges, new messages, and media thumbnails.

### 1.2 Dynamic Windows / Wallpaper Engine Accent Color
- Resolution in `window_themes_embedded.cpp`: `DwmGetColorizationColor`, `HKCU\Software\Microsoft\Windows\DWM\AccentColor` (ABGR), `ColorizationColor` (ARGB), `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Accent\AccentPalette` (RGBA).
- Background polling in `window_theme.cpp`: `base::timer_each(1500)` -> `ApplyDefaultWithPath(path)` & `KeepApplied()`.
- Instant palette colorizer applying on settings change in `settings_custom.cpp`.

### 1.3 Downloads Categorization Router
- Target root: `Downloads/Telegram Desktop/` (`Изображения`, `Видео`, `Музыка`, `Документы`, `Архивы`, `Программы`, `Разное`).
- Hooked in `core/file_utilities.cpp` (`filedialogDefaultName`) and `data/data_document.cpp` (`DocumentMedia::bytes`).

### 1.4 Other Features
- Sponsored messages blocked in `data/components/sponsored_messages.cpp`.
- 300 recent stickers limit in `data/stickers/data_stickers.cpp`.
- Win + L auto-lock in `platform/win/main_window_win.cpp` (`WM_WTSSESSION_CHANGE`).
- Overlay game selector with 1-click removal in `settings_custom.cpp`.
